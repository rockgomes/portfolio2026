  <CaseBlock label="one file" title="All the content lives in one file" pills={['Vite', 'GSAP', 'Lenis', 'no framework']}>
    Each chapter is one object in src/data/chapters.js: its copy, its images, and which demo to mount. A different set of case studies means editing that file, never the layout.
  </CaseBlock>
  <CaseBlock label="what I would change" title="Shared demo parts, not one-offs">
    The chapter demos are hand-built per project, which does not scale. Next time I would make a small shared set of demo parts.
