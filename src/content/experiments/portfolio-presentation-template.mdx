  <CaseBlock label="the idea" title="A card that opens into a chapter">
    Click a chapter card and it zooms open into a full-screen chapter. This is a FLIP animation: the card grows smoothly into its new size and place. The chapter shows the story next to working rebuilds of the designs that shipped.

    ]} />
  </CaseBlock>
  <CaseBlock label="one file" title="All the content is in one file" pills={['Vite', 'GSAP', 'Lenis', 'no framework']}>
    Each chapter is one entry in src/data/chapters.js, with its text, its images and the demo it loads. To show different case studies, you only edit that file. The layout code stays the same.
  </CaseBlock>
  <CaseBlock label="what I would change" title="Next time, shared demo parts">
    I built each chapter demo by hand for its own project. That takes too long when there are many projects. Next time I would make a small set of demo parts that all chapters share.
  </CaseBlock>
