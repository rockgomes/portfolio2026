<CaseSection title="How it is built" subtitle="the part that was interesting" id="built">
  <CaseBlock label="the idea" title="Save it once, fill any form">
    Formalist finds the fields it can fill and puts a Fill badge in each one. Fill them all at once, or pick a value for one field. Undo puts everything back.
    <ProofStrip slot="proof" phones caption="The Formalist window: the fields it found on this page, then the same list after one click." items={[
      { src: popupDetected, label: 'form found', alt: 'The Formalist window: Form detected, 9 of 9 fields matched, a Fill 9 fields button, and the list of detected fields with Alex Taylor’s saved answers.' },
      { src: popupFilled, label: 'after Fill 9 fields', alt: 'The Formalist window after the fill: Filled 9 fields with an Undo button, and the line Nothing is submitted. You still press the form’s own button.' },
    ]} />
  </CaseBlock>
  <CaseBlock label="the hard part" title="Badges that stay with their field, even in pop-up windows">
    Real forms open in pop-up windows, sit in frames, and trap the keyboard inside a dialog. The badges must stay next to their field there too, without breaking the page. InvestEngine and Teamtailor were the test cases.
    <BadgeLayers slot="proof" caption="Real sites that shaped it: LinkedIn Easy Apply (#42), forms inside frames (#40), Greenhouse phone boxes (#44), InvestEngine and Teamtailor (#51)." />
  </CaseBlock>
  <CaseBlock label="a hard lesson" title="Safe by design, and open about the limits">
    Before launch I ran a security audit and proved each attack on test pages. Version 1.2.1 fixes three of the four problems. The fourth is written down openly in the repo.
    <ProofList slot="proof" heading="security audit, 2026-10-16 · each attack proved on test pages" items={[
      { key: 'fixed', tone: 'positive', text: 'A page could hide fields and read what was filled. Now only visible fields get filled.' },
      { key: 'fixed', tone: 'positive', text: 'A page could read the picker’s text with window.find(). Now it cannot.' },
      { key: 'fixed', tone: 'positive', text: 'The extension’s font worked as a tracking ID across sites. Now it uses the system font.' },
      { key: 'fixed', tone: 'positive', text: 'A broken backup file could stop the extension. Now settings are checked.' },
      { key: 'known limit', tone: 'neutral', text: 'A page can hide a badge under its own button. Written down in SECURITY.md.' },
    ]} />
  </CaseBlock>
  <CaseBlock label="how it was made" title="Built with AI, reviewed like a team">
    I designed in Figma and built with Claude Code. Every change, more than 50 so far, went through a branch, a pull request, tests in CI, and my review.
    <ProofList slot="proof" caption="8 of the merged pull requests, from the first commit on 7 September to the security update on 29 October." items={[
